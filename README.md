### COAL

Computer Organization and Assembly Language (COAL) is a Computer Science course that explains how a computer's hardware components work together to execute instructions. It focuses on the internal structure of a computer, including the CPU, registers, memory, buses, and input/output devices. In this course, students learn about number systems, binary arithmetic, data representation, instruction formats, addressing modes, and the fetch-decode-execute cycle. They also study assembly language programming, basic processor instructions, arithmetic and logical operations, loops, conditional jumps, and stack operations. Using tools such as EMU8086, students can write and execute assembly language programs to understand how high-level programming concepts are translated into machine-level instructions. COAL builds a strong foundation for understanding processor architecture, low-level programming, and the relationship between hardware and software.
